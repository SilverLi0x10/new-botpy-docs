示例 ​

SDK 提供了 20+ 完整示例代码，涵盖各种消息类型和业务场景。示例代码存放在项目根目录的 examples/ 目录下。

运行示例 ​

所有示例都需要创建 config.yaml 配置文件：

yaml
appid: "你的AppID"
secret: "你的AppSecret"

然后直接运行对应的 Python 文件：

bash
python examples/demo_at_reply.py

前置条件 ​

  1. 在 QQ 机器人平台 注册机器人并获取 AppID 和 Secret
  2. 根据机器人类型（公域/私域）配置相应的 Intents
  3. 将机器人添加到频道/群聊中
